Deployment Guide · MacBook → Always-On

Run the Second Entry bot 24/7 — from a Mac

A plain-language walkthrough: get the bot trading on MetaTrader 5, paper-trade it on a demo account, then go live — and keep it running even when your MacBook is closed or off.

The one thing to understand first

The bot cannot run on your Mac — MetaTrader 5's Python link is Windows-only — and a laptop that's off can't trade. Both problems have the same fix: rent a tiny Windows computer in the cloud (a "VPS") that's always on. You set it up once from your Mac, then it runs by itself.

Your Mac → remote-controls → Windows VPS (always on) → runs → MT5 + bot → trades with → your broker
1

Get the two accounts you need

  • A broker MT5 demo account. Sign up with any MT5 broker and open a demo account — you'll get a login number, password, and server name. (Demo = fake money = paper trading.)
  • A Windows VPS. Either your broker's VPS (many offer one free if you fund the account), or a general provider — Amazon Lightsail, Vultr, or Contabo all rent a Windows VPS for roughly $5–20/month. Choose a Windows plan near your broker's servers.
Why not MT5's own free "VPS"? That built-in VPS only runs MQL5 Expert Advisors, not external Python programs. For this Python bot you need a real Windows VPS. (If you'd rather use MT5's built-in VPS, that means porting to a native MQL5 EA — ask and I'll help.)
2

Connect to the VPS from your Mac

  • Install Windows App (formerly "Microsoft Remote Desktop") from the Mac App Store — it's free.
  • Add a PC using the VPS's IP address, username, and password (your VPS provider emails these).
  • Double-click it — a Windows desktop opens in a window on your Mac. Everything from here happens inside that window.
3

Set up MetaTrader 5 on the VPS

  • Inside the Windows window: download and install MetaTrader 5 from your broker.
  • Log in with your demo account (login, password, server).
  • Turn on automation: Tools → Options → Expert Advisors → ✓ Allow algorithmic trading, then click the "Algo Trading" toolbar button so it's green.
4

Install the bot on the VPS

  • Install Python 3.11 (64-bit) from python.org — tick "Add Python to PATH" during setup.
  • Download the bot: get the Second-entries project (Download ZIP from GitHub, or install Git and clone it).
  • Open Command Prompt, go to the folder, and install the requirements: 
    cd path\to\Second-entries
pip install -r requirements.txt
  • Prove the link works (this trades nothing): 
    python mt5_connect_test.py EURUSD
    You should see your demo account and "Link looks good."
Prefer clicking to typing? Open the folder in VS Code, press F5, and pick "1 · MT5: Connection test" — the project ships with the run buttons already set up.
5
Paper trading

Paper-trade on the demo account

Two safe stages before any real order is sent.

  1. Watch-only (a few days). The bot ships with DRY_RUN = True — run python mt5_live_bot.py and it logs the trades it would make without placing them. Confirm the signals look sane.
  2. Real demo orders (2–4 weeks). Set DRY_RUN = False in mt5_live_bot.py and run it again. Now it places actual orders on your demo account — real paper trading, real fills, zero real money.
This is where you find out how it really behaves — spread, fills, and timing that a backtest can't show. Let it run for weeks.
6
Always on

Keep it running when your Mac is off

This is the whole point of the VPS — it's a separate computer that never sleeps.

  • When you're done checking in, just close the Remote Desktop window (or quit Windows App). Choose Disconnect, not "Sign out" — disconnect leaves MT5 and the bot running; signing out stops them.
  • Your Mac can now be shut, closed, or offline — the VPS keeps trading.
  • Survive VPS reboots: put a shortcut to the bot in Windows' Startup folder (press Win+R, type shell:startup, drop a shortcut there) and set MT5 to launch on login, so everything restarts by itself after any reboot.
  • Reconnect anytime from your Mac to check the log or equity.
7
Live money

Go live — only after demo proves out

  • In MT5, log in to your live account instead of the demo.
  • Start tiny: the bot risks 1% per trade — consider lowering RISK_PERCENT to 0.25–0.5% at first, and trade one or two pairs.
  • Watch it daily for the first weeks. Scale up only if live behaviour matches what you saw on demo.

What it costs

  • VPS: ~$5–20/month (or free from some brokers with a funded account).
  • MT5, Python, the bot: free.
  • Remote Desktop app on Mac: free.

Before you risk real money — the honest part

  • The results so far ignore real trading costs. Spread and slippage will lower the edge, most on the fast M3 timeframe. Demo is how you measure the real number.
  • Not battle-tested. This bot hasn't run on a live terminal yet — you are the first real test. Weeks on demo, then tiny live size.
  • Keep the demo running alongside live for a while to compare.
  • Never risk money you can't afford to lose. Automated trading can lose steadily as well as win.
