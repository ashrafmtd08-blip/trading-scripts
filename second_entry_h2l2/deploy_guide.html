Deployment Runbook · MacBook → Always-On

Take the bot live — and keep it trading 24/7

A calm, do-this-then-that guide to running the Second Entry (H2/L2) bot on MetaTrader 5: paper-trade it on a demo account, keep it running while your MacBook is closed, then go live when you're ready.

↳

The one idea that makes everything click: the bot can't run on your Mac (MT5's Python link is Windows-only) and a laptop that's off can't trade — so it lives on a small always-on Windows PC in the cloud (a “VPS”). You set it up once from your Mac; it runs on its own.

Act I

Set up the machine

A one-time setup you do by remote-controlling a cloud PC from your Mac. ~30–45 minutes.

1

Get two accounts

  • A broker MT5 demo account. Open a demo with any MT5 broker — you'll get a login number, password, and server name. Demo = fake money = paper trading.
  • A Windows VPS. Your broker's VPS (often free with a funded account), or a provider like Amazon Lightsail, Vultr, or Contabo — about $5–20/month. Pick a Windows plan hosted near your broker's servers.
Skip MT5's own free “VPS.” It only runs MQL5 Expert Advisors, not Python programs. For this bot you need a real Windows VPS. (Want the built-in route instead? That means a native MQL5 EA — just ask.)
2

Remote into the VPS from your Mac

  • Install Windows App (formerly “Microsoft Remote Desktop”) from the Mac App Store — free.
  • Add a PC with the VPS's IP address, username, and password (your provider emails these).
  • Double-click it — a Windows desktop opens in a window on your Mac. Everything below happens inside that window.
3

Install MetaTrader 5 and log in to demo

  • Download and install MetaTrader 5 from your broker.
  • Log in with your demo account (login, password, server).
  • Turn on automation: Tools → Options → Expert Advisors → ✓ Allow algorithmic trading, then click the “Algo Trading” toolbar button so it glows green.
4

Install the bot & test the link

  • Install Python 3.11 (64-bit) from python.org — tick “Add Python to PATH.”
  • Download the Second-entries project from GitHub (green Code → Download ZIP) and unzip it.
  • Open the folder, then install the requirements and test the link:
Command Prompt — Second-entries
C:\Second-entries> pip install -r requirements.txt
C:\Second-entries> python mt5_connect_test.py EURUSD
  ✓ Linked to the MT5 terminal.
  ✓ Link looks good — you can run the bot.
Rather click than type? Just double-click run_connection_test.bat in the folder — same thing, no typing. Or open the folder in VS Code and press F5 → “1 · MT5: Connection test.”
Act II

Paper-trade on demo

Two safe stages — no real money touched — that tell you how it actually behaves. Give it weeks, not hours.

5

Run it on the demo account

  1. Watch-only (a few days). The bot ships with DRY_RUN = True — it logs the trades it would place, without placing them. Double-click run_bot.bat and read the log; confirm the signals look sane.
  2. Real demo orders (2–4 weeks). Open mt5_live_bot.py, set DRY_RUN = False, and run again. Now it places actual orders on your demo account — real fills, real spread, zero real money.
run_bot.bat
[12:03:07]  Bot running on M3. Ctrl-C to stop.
[12:41:22]  SIGNAL EURUSD BUY entry=1.0912 sl=1.0901 tp=1.0934
[12:41:22]  ORDER OK EURUSD BUY 0.42 lots ticket=5573100
This is the real test — spread, fills and timing a backtest can't show. The bot auto-restarts if it hiccups, so you can leave it.
Act III

Stay on & go live

Make it run without you, then — only after demo proves out — put real money behind it, carefully.

6

Keep it running when your Mac is off

This is the entire reason for the VPS — a separate computer that never sleeps.

  • When you're done checking in, close the Remote Desktop window and choose Disconnect — not “Sign out.” Disconnect leaves MT5 and the bot running; signing out stops them.
  • Your Mac can now be shut, closed, or offline. The VPS keeps trading.
  • Survive reboots automatically: double-click install_autostart.bat once. The bot will relaunch on every login/restart (set the VPS to auto-login so it's hands-off). Undo with uninstall_autostart.bat.
  • Reconnect from your Mac any time to glance at the log.
7

Go live — small, and only when ready

  • In MT5, log in to your live account instead of the demo.
  • Start tiny: lower RISK_PERCENT from 1 to 0.25–0.5 and trade one or two pairs at first.
  • Watch it daily for the first weeks; scale up only if live behaviour matches demo.

What it costs

  • VPS: ~$5–20/month (or free from some brokers with a funded account)
  • MT5, Python, the bot: free
  • Remote Desktop on Mac: free

Before real money

  • Costs aren't in the results yet. Spread & slippage lower the edge — most on fast M3. Demo measures the real number.
  • Not battle-tested. This bot hasn't run live — you're the first test. Weeks on demo, then tiny size.
  • Never risk money you can't afford to lose.
